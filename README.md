# Shopping List App

Приложение для списка покупок на Android с использованием чистой архитектуры.

## Технологии
- Jetpack Compose (без XML)
- Clean Architecture + MVVM
- Room (локальное хранение)
- DataStore (настройки темы и языка)
- Hilt (dependency injection)
- Coroutines + Flow
- Foreground Service (кнопка "За покупками")

## Функции
- Добавление, удаление, редактирование товаров
- Вычёркивание товаров
- Тёмная/светлая тема
- Русский/английский язык
- Сохранение списка после закрытия
- Фоновый сервис с уведомлениями "За покупками"
